# นโยบายเนื้อหาและการใช้งาน (Standard Mode) — KRUTH AI Studio

เวอร์ชัน 2026-09-07 · บังคับใช้กับทุกโหมดในแพลตฟอร์มนี้ (Video Gen, Image Gen, Dialogue Engine, VFX Studio, Film Mode)

## 1. ขอบเขต
แพลตฟอร์มนี้ให้บริการ **Standard Mode เท่านั้น**: งานโปรดักชั่นสื่อทั่วไปตามนโยบายของผู้ให้บริการโมเดล (Fal.ai และโมเดลปลายทาง) ตัวกรองความปลอดภัยของผู้ให้บริการเปิดอยู่เสมอ ระบบไม่มีและจะไม่มีกลไก "ช่วยให้ผ่าน" ตัวกรอง — เมื่อผู้ให้บริการปฏิเสธงาน ระบบจบคำขอและแจ้งเหตุผลตรงไปตรงมา

## 2. สิ่งที่บล็อกถาวร (ระบบปฏิเสธก่อนส่งงานและระหว่างตรวจ)
- เนื้อหาทางเพศทุกรูปแบบที่เกี่ยวข้องกับผู้เยาว์ หรือบุคคล/ตัวละครที่อายุคลุมเครือ
- เนื้อหาทางเพศของบุคคลจริงที่ระบุตัวได้ และ deepfake ทางเพศทุกกรณี
- ความรุนแรงทางเพศ การบังคับขืนใจ (coercion) และการทำให้เสื่อมเสียโดยไม่ยินยอม
- การแอบอ้างเป็นบุคคลจริงเพื่อหลอกลวง ข้อมูลเท็จที่เป็นอันตราย และการคุกคามบุคคล
- การใช้ภาพลักษณ์บุคคลจริง (ใบหน้า เสียง) โดยไม่มี **บันทึกความยินยอม** ในระบบ — บุคคลสาธารณะถูกปฏิเสธเสมอ

## 3. ภาพลักษณ์บุคคลจริง
การใช้ใบหน้าจริง (ตัวละคร LoRA, Motion Control, character layer) ต้องมีบันทึกความยินยอม (consent record) ที่ระบุตัวบุคคล ฐานความยินยอม (ตัวเอง / หนังสือยินยอม) และผ่านการคัดกรองบุคคลสาธารณะ ทุกผลงานที่มี character edit ติดลายน้ำและ metadata อ้างอิงบันทึกนั้น

## 4. Provenance และการติดฉลาก
ทุกผลงานถูกบันทึกว่าเป็น AI-generated พร้อม endpoint/โมเดลที่ใช้ ผู้สร้าง เวลา และเวอร์ชันนโยบาย (`metadata.provenance`) ผลงานที่มีการแก้ตัวละครมีลายน้ำมองเห็นได้และ metadata ในไฟล์

## 5. การรายงานและการถอดเนื้อหา (takedown)
- ผู้ใช้รายงานผลงานได้จากคลังผลงาน (เหตุผล: ภาพลักษณ์ของฉันโดยไม่ยินยอม / ผู้เยาว์ / ความรุนแรงทางเพศ / หลอกลวง-แอบอ้าง / ลิขสิทธิ์ / อื่นๆ)
- รายงานเข้า **คิวตรวจ** ผู้ตรวจ (reviewer/admin) ตัดสินภายใน 24 ชั่วโมงทำการ: ยกคำร้อง / ลบผลงาน / ระงับตัวละคร / ระงับบัญชี
- ทุกการตัดสินถูกบันทึกใน audit log พร้อมผู้ตัดสินและเหตุผล ผลงานที่ถูกลบจะถูกลบไฟล์จริงออกจากคลัง

## 6. บทบาท
- **user** สร้างงานตามสิทธิ์และเครดิตของตน
- **reviewer** เห็นคิวรายงาน ตัดสินคำร้อง ระงับตัวละคร ลบผลงาน (ไม่เห็นการตั้งค่าระบบ/การเงิน)
- **admin** ทุกอย่างของ reviewer + สิทธิ์ผู้ใช้ เครดิต แพ็กเกจ ราคา และการตั้งค่าระบบ

## 7. ความลับและการเข้าถึง
คีย์ผู้ให้บริการทุกตัวอยู่ฝั่งเซิร์ฟเวอร์เท่านั้น (ชื่อตัวแปรห้ามขึ้นต้น `NEXT_PUBLIC_`) การส่งงานไปผู้ให้บริการทำผ่านเส้นทางภายในของระบบ (`/api/*`) เท่านั้น เบราว์เซอร์ไม่เคยถือคีย์

## 8. การเก็บรักษา
ไฟล์ผู้ใช้ (ฟุตเทจ ภาพอ้างอิง เสียง) และผลงานเก็บในคลังของแพลตฟอร์ม ผู้ใช้ลบผลงานของตนได้ทุกเมื่อ ระบบลบผลงานตามคำตัดสิน takedown ทันที บันทึกความยินยอมและ audit log เก็บไว้ตามที่กฎหมายกำหนดแม้ผลงานถูกลบ

## 9. โหมดอื่น
โหมดที่มีเนื้อหาสำหรับผู้ใหญ่ **ไม่อยู่ในแพลตฟอร์มนี้** และจะไม่ถูกเพิ่มในโค้ดเบสนี้ หากจะมีในอนาคตต้องเป็นโปรดักต์แยก ภายใต้ความเห็นทางกฎหมาย การยืนยันอายุ และช่องทางชำระเงินที่รองรับ ซึ่งยังไม่มีข้อสรุป
